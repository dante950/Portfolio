# 내 포트폴리오 템플릿

원본의 글꼴, 스크롤 배경 전환, 이미지 콜라주를 바탕으로 만든 로컬 포트폴리오입니다. 활동과 기획·검증 영역은 제공된 경험을 반영했으며, 소개와 Selected Works에 남은 입력용 문구는 아직 실제 이력으로 교체하지 않은 틀입니다.

## 화면 열기

**YouTube 영상 재생은 아래의 `미리보기.cmd`로 연 웹 미리보기를 사용하세요.** HTML 파일을 직접 여는 `file:` 환경은 YouTube에 페이지 출처를 전달할 수 없어 오류 153이 발생할 수 있습니다. 단일 HTML에서는 오류 플레이어 대신 웹 미리보기 안내와 YouTube 링크를 표시합니다.

설치 없이 완성된 틀을 둘러보려면 **포트폴리오 미리보기.html**을 더블클릭하세요. 이미지와 스타일을 한 파일에 담은 미리보기입니다. 이 파일은 빌드 시 갱신되며, 원본 데이터를 수정해도 자동 갱신되지는 않습니다. 인터넷이 없으면 외부 글꼴 대신 시스템 글꼴이 표시됩니다.

이 폴더의 **미리보기.cmd**를 더블클릭하세요. 실행된 창을 열어 두면 브라우저에서 `http://127.0.0.1:5173/`으로 확인할 수 있습니다. 내용을 저장하면 화면에 반영됩니다. 종료할 때는 실행 창에서 `Ctrl+C`를 누르세요.

다른 컴퓨터에서는 Node.js 22.12 이상과 pnpm 11.25.0을 준비한 뒤 다음 명령을 사용합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## 내용 바꾸기

| 바꾸려는 내용 | 편집할 파일 |

| Experience 참여 프로젝트 4개·담당 역할·기간 | `src/data/projects.ts` |
| AI 협업 툴·기획서 기본 정보·영상·자료 링크 | `src/data/planning.ts` |

| 게임 분석 글·해독 기여·나무위키 반영 사례·조회/추천 기록 | `src/data/activities.ts` |
| 봉사·멘토링·수상·선발 이력 | `src/data/achievements.ts` |
| Selected Works·Work Archive 기획서 제목·분류·썸네일 | `src/data/works.ts` |
| 기획서·분석서 상세 본문 | `src/content/works/semester-event.md` 등 |
| 참여 프로젝트 상세 본문 | `src/content/personal/monster-hair-salon.md` 등 |
| Q&A 질문과 답변 | `src/data/qa.ts` |
| 로고 문구·메뉴 이름 | `src/data/navigation.ts` |

따옴표 안의 문구를 본인 내용으로 바꾸세요. 프로젝트를 추가할 때는 고유한 `id`를 만들고 `body`에 상세 본문의 파일명을 연결합니다. 첫 화면의 대표 작업은 `home.ts`의 `selectedWorks`에서 고릅니다. 순서 변경·추가·삭제가 가능합니다.

홈의 활동 카드는 **게임 분석·해석 / 봉사·멘토링 / 수상·선발**로 나뉩니다. 처음에는 첫 번째 게임 분석 카드가 펼쳐져 있습니다. 카드를 클릭하면 해당 기록이 높이와 투명도가 부드럽게 변하며 펼쳐집니다. 같은 카드를 다시 클릭하면 부드럽게 접히고, 다른 카드를 클릭하면 해당 기록으로 바뀝니다. 직접 접은 카드는 스크롤해도 다시 열리지 않습니다. 마우스를 올리면 카드가 부드럽게 커집니다. 키보드 Tab·방향키·Home/End로 카드에 이동하고 Enter·Space로 펼치거나 접을 수 있습니다. ‘마스터로보’가 직접 작성한 분석 글 3편과 해독 기여가 인용된 글 1편을 구분했습니다. 조회·추천은 제공한 캡처의 수치이며 실시간 수치가 아닙니다. 글과 활동 기사는 원문을 새 창으로 엽니다. 멘토링과 수상·선발은 제공된 노션 이력을 바탕으로 했습니다.

대표 분석 글 아래에는 나무위키 「엘라어」 문서에 해석 자료가 반영된 사례를 배치했습니다. 제공된 ‘3. 특징’ 캡처의 자모 대응표를 인벤 자료와 대조했으며, 신규 문자 해독·보완 기여를 중심으로 설명합니다. 나무위키 본문은 직접 접근이 제한되어 제공된 캡처와 사용자의 자료 확인을 기준으로 반영했습니다. 문서와 직접 작성한 해석 원문으로 각각 연결됩니다.

`public/activities`의 썸네일은 연결된 인벤 원문 이미지와 사용자가 제공한 나무위키 캡처(`elar-namuwiki.png`)입니다. 이 이미지도 빌드 시 단일 HTML 미리보기에 함께 포함됩니다. 다른 이미지 폴더를 새로 쓰면 `scripts/export-preview.mjs`의 포함 목록에 추가하세요.

이미지는 `public` 안에 넣습니다. 예를 들어 `public/images/my-project.jpg` 파일은 데이터에 `/images/my-project.jpg`로 입력합니다. 지금 있는 `public/placeholders` 이미지는 자유롭게 교체할 수 있는 자리 표시자입니다. 이메일은 빈 값으로 두었으며, 실제 이메일을 입력하면 복사 버튼이 활성화됩니다.

## 프로젝트와 주요 작업 구조

상단 메뉴는 **소개 → 프로젝트 → 주요 작업 → Q&A**입니다. 프로젝트 메뉴는 홈의 **Experience**로, 주요 작업 메뉴는 **Work Archive**로 연결됩니다.

Experience에는 **몬스터 헤어 살롱 / 프로젝트 루나 / SE:Grocery / 룰렛 오브 페블즈** 네 카드가 있습니다. 각 카드는 `#/projects/프로젝트-id`의 별도 프로젝트 상세로 이동합니다. 상세 페이지 상단에도 네 프로젝트 선택 카드가 있으며 현재 프로젝트는 진한 색과 ‘현재 프로젝트’ 문구로 표시됩니다. PC에서는 한 줄, 모바일에서는 두 줄로 배치됩니다. 기존 개인 프로젝트 페이지의 상세 형식을 활용하며, 알려지지 않은 역할·기간·이미지는 준비 중으로 남겨 두었습니다. AI 협업 툴 소개와 영상 자리는 몬스터 헤어 살롱 프로젝트 상세로 옮겼습니다.

**Selected Works**는 이벤트 기획서 → 몬스터 헤어 시스템 기획서 → 킹덤러쉬 영웅 기획·데이터 설계 → 스톰빌성 분석서 순서로 보여줍니다. 각 작업은 `#/works/작업-id`의 상세로, VIEW WORK ARCHIVE는 전체 작업 목록으로 연결됩니다. 작업 상세 상단의 네 카드로 다른 작업에 바로 이동할 수 있으며, 현재 작업은 진한 색과 ‘현재 작업’ 문구로 표시됩니다. PC에서는 한 줄, 모바일에서는 두 줄로 배치됩니다. 몬스터 헤어 시스템 기획서와 해당 프로젝트 상세는 서로 연결됩니다. 툴의 기능과 팀 활용 사례는 제공된 설명을 바탕으로 했으며, 영상과 작업 썸네일은 아직 자리 표시자입니다.

파일은 `public/planning` 바로 아래에 넣고 `src/data/planning.ts`에서 다음 값을 채우세요. 비워 두면 준비 중 상태가 유지됩니다.

몬스터 헤어 살롱 상세 본문은 왼쪽 고정 목차와 한 열의 읽기 영역으로 구성됩니다. 프로젝트 소개 → 핵심 플레이 → 담당 역할 → AI를 활용한 기획 검증·협업 → 기획 문서 순서이며, 목차를 누르면 해당 위치로 이동하고 페이지 끝에서도 현재 항목을 표시합니다. 담당 역할은 `featuredTool.role`에서 수정합니다. 모바일에서는 본문 위의 접이식 CONTENTS 메뉴를 사용합니다. 본문 스크린샷을 누르면 확대 창이 열리며, 원본 크기로 전환해 스크롤할 수 있습니다. 닫기·Esc·배경 클릭으로 돌아옵니다.

- `src/data/projects.ts`의 `monsterProjectVideos.gameplay` / `simulator`: 각각 프로젝트 소개 위와 ‘시뮬레이터 플레이 영상’ 제목 아래에 표시할 YouTube 링크. 일반 영상·공유·Shorts 링크를 넣으면 페이지 안에서 재생할 수 있고, 빈 값이면 영상 준비 중 영역을 표시합니다.
- `featuredTool.videoSrc`: `/planning/tool-demo.mp4`처럼 시뮬레이터 로컬 영상 경로. YouTube 링크가 없을 때 ‘시뮬레이터 플레이 영상’ 제목 아래에 표시하며 자동 재생 없이 재생 컨트롤을 제공합니다.
- `featuredTool.posterSrc`: 영상 표지 이미지 경로.
- `featuredTool.outcomes`의 `toc`·`image`·`imageAlt`·`caption`: 미용 → 전투 → 대사 → 하루 마감 → 본편 플레이 순서의 목차 이름·화면 자료·대체 설명·캡션. 제공한 캡처는 `public/planning`에 보관하며 단일 HTML에도 포함됩니다. 상단에는 게임 소개와 PROJECT INFO를 표시하고, 시뮬레이터 체험 버튼·미리보기·기능·사례는 모두 04 AI 영역 안에 표시합니다. 하단 인트로 제안 박스와 링크 묶음은 제거했습니다.
- 각 작업의 `image`: 기획서·테이블·도면 미리보기 이미지 경로.
- `simulatorUrl`: 04 AI 영역 시뮬레이터 체험 버튼의 주소. 기획서 파일 링크는 각 작업의 Markdown 본문에 추가합니다.

이미지는 단일 HTML에 포함됩니다. 영상과 문서는 용량을 고려해 파일로 유지하므로, 이 자료를 추가한 뒤 미리보기 HTML을 다른 곳에 옮길 때는 `public/planning` 폴더도 함께 옮기세요. 내용을 바꾼 뒤 빌드하면 미리보기 HTML이 갱신됩니다.

## 배포 파일 만들기

```sh
pnpm build
pnpm preview
```

빌드 결과는 `dist` 폴더에 만들어집니다. 상대 경로와 해시 기반 페이지 이동을 사용해 하위 폴더에도 올릴 수 있습니다. 현재는 로컬 템플릿이며 외부 사이트에 배포하지 않았습니다. 검색엔진 색인 제외 메타 태그는 원본처럼 유지했습니다.
