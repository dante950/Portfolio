## 작업 개요

**2023년 당시 서비스된 로스트아크의 장비 재련 시스템을 역기획했습니다.** 장비를 선택하고 재료를 투입한 뒤 결과를 확인하기까지, 플레이어가 경험하는 과정을 시스템 규칙과 UI 동작으로 풀어 작성했습니다.

장비 성장과 재련의 선행 조건, 성공·실패 이후의 변화, 장인의 기운을 정리했습니다. 이어 각 화면의 표시 정보와 조작 조건을 정의하고, 이 규칙을 데이터로 관리한다면 어떤 항목이 필요할지 문서 안에서 구상했습니다.

이 페이지는 **2023년 당시의 분석 기록**을 소개합니다. 화면과 수치는 원본 작성 시점을 기준으로 하며, 현재 서비스 사양과는 차이가 있을 수 있습니다.

## 성장과 재련의 진행 구조

재련 과정을 **장비 선택 → 장비 성장 → 재련 시작 → 추가 재료 선택 → 결과 확인**으로 나누었습니다. 장비 성장이 다음 재련 시도의 선행 조건이 되고, 추가 재료의 선택이 성공 확률에 영향을 주는 관계를 화면 순서와 함께 정리했습니다.

![장비 선택부터 성장, 추가 재료 투입과 결과 확인까지 연결한 재련 진행 흐름](/planning/lostark-honing-flow.png "원본 9쪽 · 시스템 진행 흐름 — 재련의 주요 단계를 실제 화면과 연결해 한눈에 정리했습니다.")

### 성장·재련·추가 재료의 역할

| 분석한 구조 | 문서에 정리한 내용 |
| --- | --- |
| 장비 성장 | 성장에 필요한 재료를 투입하고, 요구 경험치를 충족하면 재련 단계로 진행하는 조건 |
| 장비 재련 | 성장이 완료된 장비에 재료와 재화를 사용해 다음 단계의 성능 향상을 시도하는 과정 |
| 추가 재료 | 보유 여부와 투입 선택에 따라 성공 확률에 영향을 주는 선택 요소 |
| 결과와 재시도 | 성공 시 장비 성능의 변화, 실패 시 누적 성공 확률과 장인의 기운의 변화 |

성장 욕구, 콘텐츠 연결, 재화 소비라는 관점에서도 재련의 역할을 분석했습니다. 재료를 획득하는 플레이와 장비를 성장시키는 과정이 어떻게 이어지는지 살펴보았습니다.

## 조건 판단과 결과 분기

플레이 순서를 정리한 뒤, **어떤 조건에서 조작할 수 있고 결과에 따라 무엇이 달라지는지**를 흐름도로 세분화했습니다. 각 단계에 번호를 붙이고 옆의 설명표와 대응시켜, 화면 출력·버튼 입력·조건 판단·데이터 변경을 함께 읽을 수 있도록 작성했습니다.

### 성장 조건과 재료 소모

![성장 완료 여부와 재료 보유 조건, 경험치 증가를 구분한 장비 성장 흐름도](/planning/lostark-honing-growth.png "원본 16쪽 · 장비 성장 흐름도 — 성장 여부와 재료 보유 조건에 따른 조작 가능 상태, 재료 소모와 경험치 증가를 정리했습니다.")

성장 단계에서는 이미 성장을 마친 장비인지, 필요한 재료를 보유했는지, 요구 경험치를 채웠는지에 따라 진행을 구분했습니다. 재료 투입 이후에는 소모 처리와 경험치 증가, 성장 완료 피드백을 연결했습니다.

### 성공·실패와 장인의 기운

![재련 성공과 실패에 따른 누적 확률, 장인의 기운, 장비 성능의 변화 흐름도](/planning/lostark-honing-result.png "원본 18쪽 · 결과 확인 흐름도 — 성공과 실패 이후 달라지는 처리와 다음 화면을 나누어 작성했습니다.")

| 결과 | 분석에서 구분한 변화 |
| --- | --- |
| 재련 실패 | 실패 결과 표시, 누적 성공 확률과 장인의 기운 상승, 확인 후 재시도 흐름 |
| 재련 성공 | 성공 결과 표시, 장인의 기운 초기화, 장비 성능과 아이템 레벨 상승 |

특히 실패 후에도 다음 시도에 영향을 주는 값이 남는다는 점에 주목했습니다. 누적 성공 확률과 장인의 기운을 각각 구분해, 반복 시도와 성장 보장 장치를 설명했습니다.

## 화면과 조작의 동작 정의

재련 UI를 장비 선택, 성장, 재료 투입, 결과 확인 화면으로 나누고, 화면의 번호와 설명표를 연결했습니다. 각 요소에 **무엇을 표시하는지, 어떤 조건에서 바뀌는지, 조작하면 어디로 이동하는지**를 정리했습니다.

## 데이터 구조 구상

### 테이블 역할과 컬럼 구성안

개인 역기획 과정에서, 분석한 규칙을 데이터로 관리한다면 **아이템·재련 비용·장비 성장·장비 재련**을 어떻게 나눌 수 있을지 구상했습니다. 필요한 컬럼의 이름, 타입, 역할과 참조할 항목을 문서 안의 표로 정리했습니다.

**문서에 수록한 데이터 구조 구상안과 예시이며, 별도의 엑셀 데이터 파일은 제작하지 않았습니다.**

![장비 정보와 성공 확률을 관리하기 위해 구상한 컬럼 구성안](/planning/lostark-honing-data.png "원본 39쪽 · 재련 데이터 구조 구상안 — 장비 정보와 기본 성공 확률, 실패 시 증가량, 누적 상한을 관리할 컬럼을 구상했습니다.")

| 구상한 테이블 | 관리할 데이터의 역할 |
| --- | --- |
| Item_Table | 아이템의 식별 정보, 이름, 유형, 등급과 기본 속성 |
| EnchantCost_Table | 재련 단계와 장비에 따른 요구 재료, 성장·재련 비용 |
| EnchantGrowth_Table | 성장 재료, 요구 경험치, 성장에 필요한 비용 |
| Enchant_Table | 장비 성능, 성공 확률과 누적 상한, 장인의 기운 및 추가 재료 관련 항목 |
