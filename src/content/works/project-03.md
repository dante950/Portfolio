## 프로젝트 개요

세 번째 프로젝트의 서비스나 기능을 소개해 주세요. 누구의 어떤 문제를 해결하려고 시작했는지 입력하세요.

## 구현 목표

필요했던 기능과 직접 구현한 범위를 정리해 주세요.

- 핵심 기능: 사용자가 할 수 있는 일을 입력하세요.
- 담당 범위: 직접 개발한 부분을 입력하세요.
- 사용 도구: 사용한 기술과 선택 이유를 입력하세요.

## 개발 과정

### 설계

전체 구조와 중요한 결정을 설명해 주세요.

### 구현과 검증

개발 중 마주한 문제, 해결 방법, 동작을 확인한 방법을 입력하세요. 설명에 필요한 화면이나 코드 링크를 추가할 수 있습니다.

## 결과와 배운 점

현재 동작하는 결과물과 확인한 성과를 입력하세요. 남은 개선점과 새롭게 배운 내용을 정리해 주세요.
