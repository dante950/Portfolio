## 작업 개요

‘맙소사 벌써 종강이라니’ 이벤트를 기획하고, 기획서와 데이터 테이블·JSON 자료를 구성했습니다.

## 작업 방향

이벤트의 진행 흐름과 이를 구성하는 데이터를 함께 살펴볼 수 있도록 정리합니다. 기획서의 내용이 데이터 테이블과 JSON에서 어떻게 표현되는지를 중심으로 소개합니다.

## 작업 내용

- **이벤트 기획:** 이벤트의 목적과 진행 흐름을 담은 기획서
- **데이터 테이블:** 이벤트에 필요한 데이터 구조와 대표 항목
- **JSON:** 테이블과 함께 구성한 데이터 자료

기획서 발췌 화면과 대표 데이터, JSON 예시를 추가할 예정입니다.

## 기획 문서

**자료 준비 중**

이벤트 기획서, 데이터 테이블, JSON 자료의 미리보기와 다운로드 링크를 추가할 예정입니다.
